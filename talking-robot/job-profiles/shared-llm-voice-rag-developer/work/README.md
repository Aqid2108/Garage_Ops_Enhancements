# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `src/` — Voice, retrieval and LLM source code.
- `knowledge-base/` — Approved public Garage@EEE knowledge files and source log.
- `prompts/` — System prompts, response rules and fallback text.
- `evaluation/` — Ten-question sheets and recorded results.
- `audio-tests/` — Microphone, speaker and latency evidence.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
