# Desk Buddy Mechanical Designer

Project: **Talking Robot — Stationary Desk Buddy**  
Assigned area: **Desktop enclosure and expressive mechanism**

## Role purpose

Design a stable, serviceable enclosure that positions the screen and audio devices correctly and protects the STS3215 movement mechanism.

## Start here

1. Read `weekly-tasks.md` and identify the current active period.
2. Read `hardware-and-interfaces.md` before wiring, coding or purchasing anything.
3. Save working files in the matching folder under `work/`.
4. Record tests in `testing-and-evidence.md` and link the actual evidence from the project repository.
5. Raise an issue when a component rating, voltage, connector, message or mechanical dimension is unknown.

## Ownership boundary

Own the stationary enclosure, mounts and movement clearances. Do not add drive motors or mobile-base hardware.

## General documents

The project timeline, complete hardware report and complete job-profile document remain at the project root. This role folder is the focused working area for the assigned member.
