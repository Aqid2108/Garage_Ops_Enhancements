# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `wiring/` — Audio, display, control and servo connection diagrams.
- `servo-config/` — STS3215 IDs, limits, speeds and safe poses.
- `display-ui/` — Expression assets and interface files.
- `audio-tests/` — Microphone and speaker measurements.
- `test-results/` — Power, startup, failure and stop evidence.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
