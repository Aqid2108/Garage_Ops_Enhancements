# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `acceptance-tests/` — Test procedures and signed results.
- `interface-register/` — Owner, producer, consumer, voltage and message interfaces.
- `fault-log/` — Faults, owners, decisions and closure evidence.
- `release-notes/` — Frozen versions, known limits and changes.
- `handover/` — Setup, troubleshooting and maintenance guides.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
