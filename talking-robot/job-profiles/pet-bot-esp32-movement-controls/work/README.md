# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `firmware/` — ESP32 source code and configuration.
- `pin-map/` — Pin assignments and connector mapping.
- `protocol/` — Raspberry Pi-to-ESP32 messages and states.
- `sensor-calibration/` — Ultrasonic and IR calibration records.
- `test-results/` — Motor, edge, obstacle and timeout results.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
