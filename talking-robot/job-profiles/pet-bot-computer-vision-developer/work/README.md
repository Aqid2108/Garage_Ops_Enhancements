# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `src/` — Vision source code.
- `camera-config/` — Resolution, frame rate and calibration/configuration.
- `models/` — Approved lightweight models and licences.
- `test-data/` — Permitted evaluation images and metadata.
- `test-results/` — Accuracy, latency and resource-use evidence.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
