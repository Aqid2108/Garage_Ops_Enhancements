# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `measurements/` — Measured component and interface dimensions.
- `cad/` — Fusion 360 source and neutral STEP exports.
- `fabrication/` — STL files, drawings and print/machining settings.
- `assembly/` — Fasteners, order of assembly and service instructions.
- `fit-checks/` — Photos and issues from physical fit testing.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
