# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `schematics/` — KiCad schematics and reviewed PDFs.
- `pcb-layout/` — PCB source, fabrication exports and design-rule results.
- `bom/` — Part numbers, quantities, suppliers and datasheets.
- `power-budget/` — Voltage rails, current estimates and measured results.
- `wiring/` — Connector pinouts and labelled harness drawings.
- `test-results/` — Electrical safety and load-test evidence.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
