# Garage@EEE Enhancements

GitHub-ready project workspace for the Talking Robot and More Tea projects.

## Structure

- `skills-journeys/` contains the separate general learning-journey document.
- `talking-robot/` contains the Pet Bot and Desk Buddy timeline, hardware report, general job profiles and role workspaces.
- `more-tea/` contains the navigation timeline, hardware report, general job profiles and role workspaces.

Open the relevant project, read its general documents, then enter the folder for your assigned job profile.
