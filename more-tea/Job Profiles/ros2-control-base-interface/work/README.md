# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `src/` — Hardware interface and conversion code.
- `config/` — ros2_control and wheel parameters.
- `interface-spec/` — Messages, units, ownership and timing.
- `measurements/` — Wheel/encoder measurements.
- `test-results/` — Odometry, timeout and restart evidence.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
