# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `measurements/` — Wheel, frame, sensor and component measurements.
- `cad/` — Fusion 360 source and neutral exports.
- `urdf/` — Robot model, meshes and frame dimensions.
- `fabrication/` — Drawings, STL and fabrication settings.
- `fit-checks/` — Photos and correction log.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
