# Weekly Tasks

Complete only the task for the active period and record the result before moving forward.

The workshop occurs once and starts on the **W9 weekend**. Physical implementation increases from W10 onward.

| Period | Assigned task | Status / evidence link |
| --- | --- | --- |
| W4 | Set up Ubuntu, ROS 2 Jazzy, Git, Docker, Linorobot2 and a Humble test environment. |  |
| W5 | Run Linorobot2 simulation and study TF, URDF/Xacro, teleoperation, /cmd_vel, /odom and /scan. |  |
| W9 weekend | Attend the single workshop and record bring-up steps, navigation faults and the W10 backlog. |  |
| W10 | Begin physical Linorobot2 integration; verify low-speed teleoperation, odometry and touchscreen goals. |  |
| W11 | Create an initial map and test simple touchscreen-selected goals; freeze the semester baseline. |  |
| 1–15 November | Complete repeatable physical bring-up, teleoperation, odometry and mapping. |  |
| 16–30 November | Configure AMCL and conservative Nav2 navigation on the saved map. |  |
| December | Demonstrate a minimum route with physical emergency stop active. |  |
| January | Tune Nav2 behaviour, recovery actions and touchscreen routes. |  |
| 1–15 February | Complete repeatability testing and handover documentation. |  |

## Protected periods

No meetings, coding, CAD, wiring, testing, purchasing deadlines or submissions are assigned during **W6, W7, recess week, W8, W12, W13 and the examination period**.
