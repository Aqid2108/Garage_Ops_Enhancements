# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `src/` — ROS 2 packages and launch files.
- `config/` — Linorobot2, Nav2, AMCL and controller parameters.
- `maps/` — Approved maps and metadata.
- `simulation/` — Jazzy simulation launch and regression evidence.
- `deployment/` — Humble container/workspace and startup instructions.
- `test-results/` — Routes, recovery and repeatability results.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
