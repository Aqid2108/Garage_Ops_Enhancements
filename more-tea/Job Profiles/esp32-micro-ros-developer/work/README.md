# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `firmware/` — ESP32 and micro-ROS source.
- `pin-map/` — PCB pins, connectors and signal directions.
- `messages/` — Topics, units, rates and timeout definitions.
- `control-tuning/` — PID and encoder scaling records.
- `test-results/` — Bench, timeout, reconnection and safety evidence.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
