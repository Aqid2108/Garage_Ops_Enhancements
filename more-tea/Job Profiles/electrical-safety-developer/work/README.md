# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `schematics/` — Power and safety circuit drawings.
- `bom/` — Exact part numbers, ratings, suppliers and datasheets.
- `power-budget/` — Estimated and measured load per rail.
- `wiring/` — Connector pinouts and harness drawings.
- `safety-tests/` — E-stop, fuse, fault and thermal evidence.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
