# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `drivers/` — Launch/config files and device rules.
- `calibration/` — IMU and sensor-orientation records.
- `frames/` — Frame names and measured transforms.
- `localization/` — robot_localization and AMCL sensor configuration.
- `test-results/` — Scan, rate, dropout and recovery evidence.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
