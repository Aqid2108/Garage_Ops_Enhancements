# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `test-plans/` — Procedures and acceptance limits.
- `test-results/` — Dated results, logs and media links.
- `fault-log/` — Failure, owner, fix and retest trail.
- `config-history/` — Configuration used for each test.
- `acceptance/` — Signed readiness summaries.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
