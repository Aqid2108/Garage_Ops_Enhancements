# Member Work Area

Save editable work here instead of placing unfinished files beside the general project documents.

- `camera/` — Calibration, configuration and perception code.
- `moveit-config/` — MoveIt 2, URDF and controller files.
- `servo-arm-config/` — Actuator IDs, limits, loads and safe poses.
- `bench-tests/` — Camera, arm and gripper evidence.
- `integration/` — Approved base/arm coordination and safety results.

Use clear filenames, include dates or version tags when useful, and do not commit passwords, private data, build caches or large temporary files.
